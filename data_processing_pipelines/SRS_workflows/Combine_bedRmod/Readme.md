# SRS bedRMod Merge Pipeline

This directory contains scripts and workflows to merge short-read sequencing (SRS) bedRMod files into a single bedRMod file. The workflow consists of three steps: (1) merging biological replicates generated by the same method, (2) merging different methods detecting the same RNA modification, and (3) concatenating bedRMod files from different modification types and RNA types into a final SRS bedRMod file.

## Scripts/Workflows

| File                    | Purpose                                                                                                                                                                                                                                           |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Combined_replicates.R` | Merges bedRMod files from biological replicates generated by the same method. Coverage is summed across replicates, modification frequency is averaged, and sites supported by fewer than the specified minimum number of replicates are removed. |
| `Combine_methods.R`     | Merges bedRMod files generated by different methods detecting the same RNA modification. Sites from each method are ranked according to their scores and coverage before merging.                                                                 |
| `awk`                   | Concatenates bedRMod files from different modification types and RNA types while retaining the `#`-prefixed header only once.                                                                                                                     |

## Requirements & Setup

The two R scripts require R>=4.3.3 and the following R packages:

- optparse>=1.8.2
- tidyverse>=2.0.0
- data.table>=1.15.4


## Input data

### Input files

The input files should be tab-separated bedRMod (`bedRModv2`) with `#key=value` metadata header for each replicate, with six additonal columns:

- `nRep`: number of replicates that the site is detected, always `1` in the bedRmod for a single replicate
- `repName`: name for each sample (replicate), seperate by ";" for multiple samples
- `repScore`: score for each sample (replicate), seperate by ";" for multiple samples
- `repCov`: coverage for each sample (replicate), seperate by ";" for multiple samples
- `repFreq`: frequency for each sample (replicate), seperate by ";" for multiple samples
- `method`: detection method for each sample (replicate), seperate by ";" for multiple samples

The workflow is performed hierarchically:

```text
Replicates
    ↓
Combined_replicates.R
    ↓
Methods detecting the same modification
    ↓
Combine_methods.R
    ↓
Different modifications / RNA types
    ↓
awk
    ↓
Final SRS bedRMod
```

## Usage/Step-wise Execution

### Step 1: Merge biological replicates

For each sequencing method and modification type, merge bedRMod files from biological replicates using `Combined_replicates.R`.

```bash
Rscript Combined_replicates.R \
  -i Rep1.bed Rep2.bed Rep3.bed \
  -o Merged_replicates.bed
```

By default, a modification site must be detected in at least two replicates to be retained. This threshold can be changed using `--min_reps`:

```bash
Rscript Combined_replicates.R \
  -i Rep1.bed Rep2.bed Rep3.bed \
  -o Merged_replicates.bed \
  --min_reps 3
```

For sites retained after replicate merging, coverage is summed across replicates and modification frequency is averaged.

### Step 2: Merge different methods detecting the same modification

If the same modification is detected using multiple sequencing methods, merge the replicate-combined bedRMod files using `Combine_methods.R`.

For example, m6A sites detected by GLORI, CAM-seq and eTAM-seq can be merged as:

```bash
Rscript Combine_methods.R \
  -i GLORI_m6A.bed CAM-seq_m6A.bed eTAM-seq_m6A.bed \
  -o Merged_m6A.bed
```

The same procedure can be applied independently to other modification types.

### Step 3: Merge different modifications and RNA types

After merging replicates and methods, concatenate the resulting bedRMod files from different modification types and RNA types into a single SRS bedRMod file.

Because each bedRMod file contains a `#`-prefixed header line, the header from the first input file is retained and the header lines from subsequent files are removed.

For example:

```bash
awk 'FNR==1 && NR!=1 && /^#/ {next} {print}' \
  polyA_m6A.bed \
  polyA_m5C.bed \
  rRNA.bed \
  tRNA.bed \
  > SRS_merged.bed
```

This command retains the header from the first bedRMod file while skipping the `#`-prefixed first-line header of subsequent files.

## Outputs

| Output File                 | Format                | Step                    | Description                                                                                                                       |
| --------------------------- | --------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `Merged_replicates.bed`     | Tab-separated bedRMod | `Combined_replicates.R` | bedRMod file containing modification sites merged across biological replicates and filtered by the minimum replicate requirement. |
| `Merged_<modification>.bed` | Tab-separated bedRMod | `Combine_methods.R`     | bedRMod file containing sites merged across different methods detecting the same RNA modification.                                |
| `SRS_merged.bed`            | Tab-separated bedRMod | `awk`                   | Final SRS bedRMod file containing different modification types and RNA types with a single header line.                           |
